# Certificações do mercado financeiro (Brasil)

Ordem sugerida, da mais acessível para a mais avançada. Servem de referência de
estudo; não são exigência para usar o app.

## Locais (ANBIMA e outras)

- **CPA-10 / CPA-20:** certificações de base para quem atende clientes em banco
  ou corretora. A CPA-20 cobre produtos mais completos. Bom primeiro passo.
- **CEA:** especialista em investimentos; aprofunda assessoria e planejamento.
- **CFP:** planejamento financeiro pessoal (indicada para Wealth/Private).
- **CGA:** gestão de recursos (indicada para Asset Management).
- **CNPI:** análise de valores mobiliários (indicada para Research).

## Internacionais

- **CFA:** referência global em investimentos; três níveis, exige bastante
  estudo e inglês. Forte para IB, Asset, Research, Quant.
- **FRM:** foco em gestão de risco; indicada para Risco & Compliance e Quant.

## Como orientar

- Para quem está começando: CPA-20 costuma ser um bom alvo inicial.
- Depois, escolher a certificação conforme a área de interesse (ex.: CFP para
  Wealth, CGA para Asset, CNPI para Research, FRM para Risco).
- CFA é um objetivo de médio/longo prazo; dá para começar os estudos cedo.
